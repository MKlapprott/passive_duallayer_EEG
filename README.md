# iCanClean EEG Script Collection

Work in progress!!!

This repository contains scripts used for preprocessing EEG data using the iCanClean algorithm.
It includes parameter settings, cleaning routines, and visualizations.

## Requirements
- MATLAB R202x
- EEGLAB
- iCanClean plugin
- loadxdf plugin

## Folder structure
- `scripts/`: All main preprocessing scripts
- `data/`: Raw or preprocessed EEG files (not committed)
- `results/`: Outputs like cleaned data or figures

## How to use
Edit and run the main script in `scripts/`, adjusting parameters as needed.
